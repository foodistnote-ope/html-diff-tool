# HTML Diff Tool & Visual Editor

WordPress等のブログ記事校正に特化した、HTML差分チェック & ビジュアル編集ツールです。

## 🚀 主な機能

- **HTML差分比較**: 校正前と校正後のHTMLコードを文字レベルで比較し、差分を視覚化します。
- **ビジュアル編集**: プレビュー画面で直接テキストを編集でき、即座にHTMLコードに反映されます。
- **クイック装飾**: ツールバーから「見出し(H2, H3)」「箇条書きリスト」をワンクリックで挿入可能です。
- **alt属性チェック**: 画像（imgタグ）のalt属性が未設定または空の場合に警告を表示し、アクセシビリティをサポートします。
- **スクロール同期**: 左（校正前）と右（校正後）のスクロール位置を自動で同期し、比較をスムーズにします。
- **トップへ戻る**: 長いコンテンツでもワンクリックで一番上まで戻れるフローティングボタン。
- **一括切替**: 全てのカラムを「ビジュアル確認」モードに一括で切り替えられます。

## 🛠 使い方

1. `index.html`をブラウザで開きます。
2. 左側の「HTMLコード表示」に校正前のHTMLを貼り付けます。
3. 右側のエディタに校正後のHTMLを貼り付けるか、直接編集します。
4. 「比較する」ボタンで差分を確認します。
5. 完成したら「最終版HTMLをコピー」ボタンでコピーして、ブログ投稿画面に貼り付けます。

## 🌐 ウェブへのアップロード方法

このツールはサーバーサイドのプログラムを必要としない「Vanilla JS/HTML/CSS」で構成されているため、以下のサービスにフォルダごとアップロードするだけで無料で使用可能です。

### 1. Netlify (推奨: ドラッグ＆ドロップで公開)
- [Netlify Drop](https://app.netlify.com/drop) にアクセスします。
- このプロジェクトのフォルダをそのままドラッグ＆ドロップするだけで、数秒で公開URLが発行されます。

### 2. Vercel
- [Vercel](https://vercel.com/) にログインし、プロジェクトフォルダをアップロードまたはGitHub連携でデプロイ可能です。

### 3. GitHub Pages
- GitHubのリポジトリを作成してファイルをアップロードし、Settings > Pages から「main」ブランチを選択して保存するだけで公開できます。
